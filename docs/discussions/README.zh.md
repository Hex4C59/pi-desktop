## 维护原则

- 默认每个重要最终文档对应一份持续追加的 discussion。
- 不为每次聊天机械地创建新文件。
- 不逐字复制完整聊天。
- 明确区分用户观点、代理建议和最终确认。
- 不删除早期错误或犹豫，后续用新时间条目标记取代。
- 不根据最终结论反向编造当时的思考。
- 更新 discussion 时同步检查对应最终文档和[文档索引](../README.zh.md)。
